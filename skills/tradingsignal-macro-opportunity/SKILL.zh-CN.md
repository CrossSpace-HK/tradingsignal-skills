# TradingSignal Macro Opportunity（兼容包）

这是旧 `$tradingsignal-macro-opportunity` 的中文阅读页。该包仅为已安装用户保留兼容；新用户请安装统一入口 [`$tradingsignal`](../tradingsignal/SKILL.zh-CN.md)。

旧工作流用于扫描加密货币、外汇、现货大宗商品和已支持的期货，先筛选全市场，再对最好的 5–10 个候选分别调用 VCP、缠论、威科夫、TD9 与多周期支撑阻力，最后最多输出 1–3 个有条件的交易动作。

每个动作必须包含方向、持有周期、入场区或触发条件、失效位、目标、风险收益比和有效期；每条关键理由必须紧跟同标的、同周期、同模块的图表。没有明确失效位不得给入场动作，用户没有提供组合风险预算时不得给仓位大小。

高周期定义市场状态，低周期优化入场。`notApplicable`、无法计算、中性和无信号必须区分。不同市场筛选池的相对强弱百分位不能直接横向比较；外汇不能使用未标注有效代理的量能结论；现货不得冒充期货。

自动斐波那契仍是探索功能。在完成样本外校准并通过邻近锚点和普通支撑阻力对照前，不得用于筛选权重、强共振或交易动作。

数据过期、结构方法明显冲突或图表缺失时，应返回 `WATCH` 或 `AVOID`，不得为凑数强行给方向。
