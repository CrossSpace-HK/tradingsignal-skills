name: ts-synthesis
description: Compose a public multi-timeframe technical research report with traceable claims.
---

Lead with action or observation, then short bullets tied to evidence IDs and their frozen charts. Explain conflicts and missing methods. Directional claims require explicit horizon and post-publication evaluation rules. A short view does not imply borrow or execution access. Never invent confidence, return or target prices.

Use the supplied research snapshot ID and decisionAt throughout. Read the registered method evidence through the research report/skill artifact interface; ordinary latest-data MCP tools are not interchangeable with a pinned snapshot. If only live tools are available, disclose that and do not claim frozen or historical acceptance.

Retain source freshness, adjustment/PIT unknowns and applicability flags. Never fill missing candles or recompute a different indicator formula in prose. Keep chart, numbers and claim tied to the same input hash. Preserve uncertainty or abstain when evidence is insufficient.

Use `get_research_report` with `reportId` to read a published pinned report, or omit IDs to discover reports. `skillId` selects one method instruction. The tool does not enqueue or publish analysis.

For platform output, reference existing evidence IDs and comply with the release JSON contract. These instructions grant no scheduling, public publication, trading, credential or future-data permission. A release is identified by its enforced manifest digest.
