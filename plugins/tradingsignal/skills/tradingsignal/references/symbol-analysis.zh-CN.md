# 单标的分析

用于用户指定标的、周期或技术方法，并希望得到解释而不是全市场扫描的情况。

## 限定问题

支持范围不确定时调用 `describe_capabilities`。识别用户的持有周期，并为每个分析周期分配明确角色。用户只问一种方法时，不要为了制造共振而调用无关引擎。

只有用户明确需要快速概览时才用 `analyze_symbol`。深度研究应独立调用颗粒化模块：VCP 看阶段、趋势模板、收缩质量、枢轴和止损；缠论看笔、中枢、结构点、确认和失效；威科夫看区间质量、阶段、事件、入场、止损和目标；TD9 看 setup/countdown 成熟度、TDST、风险线和下一根确认；`get_levels` 看支撑阻力、聚类和距离；必要时才用 `get_candles` 或 `run_engine` 补充原始证据。

**研究单只标的时，趋势强度和指标共振是必做项，不是可选项。** 用 `get_indicators` 取：
它按六大类（趋势／动量／波动／量能／形态／支撑阻力）给出各有几个看多几个看空，
以及**具体是哪些指标在表态和它们各自的理由**。`side: "decisive"` 只留真正表态的那些，
这通常就是用户想问的——不是"全部指标怎么说"，而是"现在到底有哪几个在表态"。

`get_indicators` 还会返回**两张图**，都排在所有方法图之前：方法图画的是某一个方法的
内部结构，这两张画的是结论。`chart` 是技术分析主图——均线 / MACD / RSI 固定画，
另外按 `notability` 最多再选三个，总共六个。`trendChart` 是综合趋势强弱（带方向正负号、
画出无趋势阈值带）。把你自己那一句观点作为 `conclusion` 传进去，两张图上都会印出来。

主图会跟着列表收窄：用 `categories` 或 `side` 过滤，图上就只画同一批，永远不会比正文多说。
趋势强弱图**不收窄**——强弱是所有贡献指标合成的，过滤过的那条线就不是这个数了。

两张图画的都是最后一根**已收盘**K线并带自己的 `barTs`；如果和读数的 `barTs` 不同，
说明最新一根还在走——明确说你指的是哪一根，不要让两者混为一谈。

`readings` 是列式的：`readings.fields` 给出列名，每一类下面是按该顺序排列的行，
比同样内容用对象写省大约四分之一。`notability` 为 null 表示这条读数没有表态。

**按 `notability` 排序，并且不要把固定画上去的线当成共识。** 每条读数都带
`notability`（0–100）和 `barsSinceFlip`：多久前转向，加上这个指标平时多罕见地这样读。
`notable` 给出画了哪几个、哪几个是固定位（`core: true`）、其余每个为什么被选中。
均线、MACD、RSI 不管读数如何都会出现在图上，所以正文必须写清真正表态的是哪几个。

**没有明确结论的方法就不要写——所有方法都一样，不只是威科夫。** 硬写出来，
读者会把一个默认值读成一个判断，而且他分不出来。也不要写"省略"本身：
「缠论无明显结论」这句话长得像一个发现。只有用户直接问这个方法时才说，且一句话带上原因。

每个引擎都声明过自己什么时候没什么可说：威科夫无法区分派发与上涨中继的再吸筹，
`tr.quality < 0.5` 不算可交易；VCP 的 `nearMissReason` 表示没检出形态，`unavailable`
表示评分是在更少因子上算的；缠论 `sureness: "MAYBE"` 的笔尚未确认，接近阈值的背驰
`ratio` 是一刀切不是发现；TD9 还在计数中说明的是成熟度不是方向；斐波那契节奏是探索层，
不得算作强共振证据。完整清单见 `references/obsidian-vault.zh-CN.md`。

不能把一体化概览或同一引擎的两个结果当成独立证据。保留所有注意事项，并区分无法计算和中性读数。

## 解释结果

**第一句就给观点**（买入／卖出／中性），**紧接着一句趋势强度与指标共振**——
这两样是"为什么是这个观点"最快的回答，不要留到最后。接着，仍然在任何方法细节之前，
**列出重要的看多与看空信号，并放上信号图**：读者应该先看到这张图和图上那几个读数，
再读关于缠论或威科夫的任何一句话。图里有的内容才是真正会被读到的部分，
把它压在方法段落下面等于浪费。然后再说明：

1. 高周期市场状态；
2. 当前结构与触发状态；
3. 最近的支撑、阻力和候选失效位；
4. 独立方法之间的一致与冲突；
5. 下一根 K 线或价格事件如何确认或否定当前判断。

每个方法自己的同标的、同周期图紧跟其理由，排在头图（信号图）之后。无法从图上确认关键方法时应说明，结论不得高于 `WATCH`。
