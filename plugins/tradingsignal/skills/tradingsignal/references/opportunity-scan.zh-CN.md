# 市场机会筛选基础流程

用于跨市场发现、领头羊、新近转强、回调重启、突破、反转，以及“今天是否有有效交易”的请求。

## 1. 确认可搜索范围

调用 `describe_capabilities`，报告不支持的市场或周期。深度分析前先使用预计算的 `screen_market`；请求完整相关筛选池，不能让很小的默认 limit 冒充全市场扫描。

加密货币、外汇和现货大宗商品应比较已支持的 1h、4h、1d。旧 `=F` 期货是不同的标的：先筛选可用的日线行，入选后才在支持时做 1w/1mo 实时分析。

## 2. 生成候选

- `strong`、`fresh_strength`：既有领头羊和新近趋势对齐；
- `breakout`：延续突破触发；
- `near_cost`：强势标的回调到合理成本，而不是追高；
- `div_bull`、`div_bear`、`td_buy`、`td_sell`、`chan_buy`、`wyckoff_accum`：反转或衰竭观察池。

每个候选分别评价：

1. **它现在站在哪里**：高周期阶段、趋势、均线位置，以及在同市场筛选池里的领先程度；
2. **刚刚发生了什么**：新出现的共振、突破、缠论点位、TD9 成熟度、威科夫事件或背离；
3. **上下还有多少空间**：入场到失效位的距离，以及入场到下一个合理目标的距离。

这三项用大白话写出来，**不要用 `regime`、`trigger`、`payoff` 这些标签**——对读报告的人来说那是黑话。

除非有经过校准的模型，不得把排序说成胜率。

## 3. 识别有效多周期结构

优先考虑：1d/4h/1h 同向延续；1d 定义趋势、4h 有序逆向回调且结构未坏、1h 顺高周期重启；或至少两个独立结构方法同意且高周期风险可控的反转。空头使用镜像逻辑。

单一震荡指标不是结构确认；同一引擎派生出的多个结果不是独立共振。

## 4. 只验证入选标的

只深挖最好的 5–10 个候选：VCP 看阶段、趋势模板、枢轴和止损；缠论看结构点、中枢、确认和失效；威科夫看区间、阶段、事件、入场、止损和目标；TD9 看计数成熟度、TDST、风险线和下一根确认；`get_levels` 看多周期支撑阻力及聚类；只有颗粒化结果缺证据或用户明确需要原始输出时才用 `get_candles` 或 `run_engine`。

已确认、有效且近期的结构优先于过期或未确认信号。指标影响决策时，保留名称/id、数值、状态、周期与阈值规则。

## 5. 返回决策

先回答是否存在可执行机会，再给最多 1–3 个 `topActions`，随后是 `watchlist`、`avoided` 和 `coverageGaps`。

每个候选都按 SKILL.md 里的报告结构来写——先给动作，然后入场 / 出场 / 它在哪 / 风险这四条——不要在这里另立结构。动作是这五个之一：回调进、突破进、观察、减仓或离场、回避。冲突与注意事项放在四条之后。

若没有标的合格，明确说明，并列出最接近但被拒绝的标的、拒绝原因和升级条件。
